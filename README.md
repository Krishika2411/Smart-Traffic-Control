# Smart Traffic Control System

## About the Project
Smart Traffic Control System is a C++ based traffic signal simulation project. It manages traffic on four roads: North, South, East, and West.

## Features
- Add vehicles to different roads
- Display road-wise traffic status
- Simulate a smart traffic signal cycle
- Rank roads according to traffic density
- Display traffic statistics
- Menu-driven program

## Technologies Used
- C++
- Standard Template Library (STL)
- Priority Queue

## How to Run
1. Download or clone this repository.
2. Open the C++ files in a C++ compiler or IDE.
3. Compile the required source file.
4. Run the executable and follow the menu.

## Purpose
This project demonstrates basic data structures, conditional logic, and traffic signal simulation using C++.
